People Analytics Tech Stack: From Reactive to Proactive

1. The Business Challenge

This is a mock challenge prepared in advance for an interview at Sofia. The starting point of our journey is the Voice of the Customer(Employees) process in place. Currently the manual labor takes about 15 hours per week. This contributes to a reactionary culture, instead of anticipating the needs of our high-performers to enable more importante and valuable work. Additionally, focusing on preventing key talent turnover.

The Goal: Design a comprehensive People Analytics tech stack that can shift the team response from reactive administrative work to a more PROACTIVE strategy: - How much does it cost us to hire someone? - Which teams have higher churn risk in the next 90 days? - How long does it take for a new hire to reach full productivity?

2. Synthetic Dataset Generation

To demonstrate technical capabilities, we generated a realistic synthetic dataset of 1000 employees with patterns that closely resemble real-world HR challenges.

import pandas as pd
import numpy as np
from datetime import datetime, timedelta
import random
import os

# Semilla para reproducibilidad
np.random.seed(42)
random.seed(42)

# Configuración
N_EMPLOYEES = 1000
TURNOVER_RATE = 0.20

# Catálogos
departments = ['Engineering', 'Sales', 'Marketing', 'HR', 'Finance', 'Operations', 'Product', 'Customer Success']
job_levels = ['Junior', 'Mid', 'Senior', 'Lead', 'Manager', 'Director']
locations = ['Mexico City', 'Monterrey', 'Guadalajara', 'Remote - MX', 'Remote - US']
work_modes = ['On-site', 'Hybrid', 'Remote']
educations = ['High School', 'Bachelor', 'Master', 'PhD']
genders = ['Female', 'Male', 'Non-binary']
termination_types = ['Voluntary', 'Involuntary', 'Layoff']

first_names = ['Ana', 'Luis', 'María', 'Carlos', 'Sofía', 'Diego', 'Valentina', 'Andrés', 'Camila', 'Javier']
last_names = ['García', 'Rodríguez', 'Martínez', 'López', 'González', 'Hernández', 'Pérez', 'Sánchez', 'Ramírez', 'Torres']

employees = []

for i in range(1, N_EMPLOYEES + 1):
    emp = {'employee_id': f'EMP{i:04d}'}
    emp['name'] = f"{random.choice(first_names)} {random.choice(last_names)}"
    emp['age'] = int(np.clip(np.random.normal(35, 10), 22, 65))
    emp['gender'] = np.random.choice(genders, p=[0.48, 0.48, 0.04])
    emp['education'] = np.random.choice(educations, p=[0.10, 0.55, 0.30, 0.05])
    
    emp['department'] = random.choice(departments)
    emp['job_level'] = random.choice(job_levels)
    emp['manager_id'] = f'MGR{random.randint(1, 50):03d}'
    emp['location'] = random.choice(locations)
    emp['work_mode'] = np.random.choice(work_modes, p=[0.30, 0.45, 0.25])
    
    days_ago = random.randint(90, 3650)
    emp['hire_date'] = (datetime(2026, 6, 23) - timedelta(days=days_ago)).strftime('%Y-%m-%d')
    emp['tenure_years'] = round(days_ago / 365.25, 1)
    
    if days_ago >= 180 and random.random() < 0.6:
        promo_days_ago = random.randint(30, days_ago - 30)
        emp['last_promotion_date'] = (datetime(2026, 6, 23) - timedelta(days=promo_days_ago)).strftime('%Y-%m-%d')
        emp['years_since_promotion'] = round(promo_days_ago / 365.25, 1)
    else:
        emp['last_promotion_date'] = None
        emp['years_since_promotion'] = emp['tenure_years']
    
    base_salaries = {
        'Junior': (25000, 45000), 'Mid': (45000, 75000), 'Senior': (75000, 120000),
        'Lead': (100000, 160000), 'Manager': (130000, 200000), 'Director': (180000, 300000)
    }
    min_sal, max_sal = base_salaries[emp['job_level']]
    emp['base_salary'] = int(np.random.uniform(min_sal, max_sal))
    emp['bonus_pct'] = round(np.random.uniform(0, 20), 1)
    midpoint = (min_sal + max_sal) / 2
    emp['compa_ratio'] = round(emp['base_salary'] / midpoint, 2)
    
    emp['performance_score'] = np.random.choice([1, 2, 3, 4, 5], p=[0.05, 0.15, 0.50, 0.25, 0.05])
    emp['last_review_date'] = (datetime(2026, 6, 23) - timedelta(days=random.randint(30, 365))).strftime('%Y-%m-%d')
    
    emp['engagement_score'] = round(np.random.uniform(1, 10), 1)
    emp['satisfaction_score'] = round(np.random.uniform(1, 10), 1)
    
    if random.random() < TURNOVER_RATE:
        emp['status'] = 'Left'
        left_days_ago = random.randint(30, min(days_ago, 730))
        emp['termination_date'] = (datetime(2026, 6, 23) - timedelta(days=left_days_ago)).strftime('%Y-%m-%d')
        emp['termination_type'] = np.random.choice(termination_types, p=[0.70, 0.15, 0.15])
        
        if emp['termination_type'] == 'Voluntary':
            emp['engagement_score'] = round(np.clip(np.random.normal(4, 1.5), 1, 6), 1)
            emp['satisfaction_score'] = round(np.clip(np.random.normal(4, 1.5), 1, 6), 1)
            emp['compa_ratio'] = round(np.clip(np.random.normal(0.85, 0.1), 0.6, 1.0), 2)
    else:
        emp['status'] = 'Active'
        emp['termination_date'] = None
        emp['termination_type'] = None
    
    emp['survey_response'] = None
    employees.append(emp)

df = pd.DataFrame(employees)

# Survey responses
survey_themes = {
    'positive': [
        "Me siento valorado en el equipo y mi manager me da buen feedback.",
        "Disfruto mucho la cultura de la empresa y el balance vida-trabajo.",
        "Las oportunidades de crecimiento son claras y me siento apoyado.",
        "Excelente ambiente laboral, mis compañeros son muy colaborativos.",
        "Estoy satisfecho con mi compensación y los beneficios que recibimos.",
        "El liderazgo es transparente y comunica bien la visión de la empresa."
    ],
    'neutral': [
        "El trabajo es estable pero me gustaría más retos.",
        "Todo está bien, aunque creo que podríamos mejorar la comunicación interna.",
        "Me gusta mi equipo pero siento que mi crecimiento está estancado.",
        "La carga de trabajo es manejable la mayoría del tiempo.",
        "Los procesos podrían ser más ágiles, pero en general estoy bien."
    ],
    'negative': [
        "Siento que mi salario no refleja mi contribución al equipo.",
        "La carga de trabajo es excesiva y no veo cambios en la estrategia.",
        "Mi manager no me da feedback constructivo ni apoya mi desarrollo.",
        "No veo oportunidades de crecimiento a largo plazo en la empresa.",
        "La comunicación desde liderazgo es confusa y genera incertidumbre.",
        "Estoy considerando otras opciones porque siento que no avanzo aquí.",
        "El balance vida-trabajo se ha deteriorado mucho en los últimos meses."
    ]
}

def generate_survey(status, engagement):
    if status == 'Left' or engagement < 4:
        theme = 'negative'
    elif engagement > 7:
        theme = 'positive'
    else:
        theme = 'neutral'
    
    base_response = random.choice(survey_themes[theme])
    
    if random.random() < 0.3:
        extra = random.choice([
            " Creo que sería útil tener más espacios de feedback.",
            " Me gustaría que se revisaran las bandas salariales.",
            " Agradezco la flexibilidad del trabajo híbrido.",
            " Sería bueno tener más capacitación técnica."
        ])
        base_response += extra
    
    return base_response

df['survey_response'] = [
    generate_survey(row['status'], row['engagement_score']) 
    for _, row in df.iterrows()
]

# Guardar CSV en carpeta data/
os.makedirs('data', exist_ok=True)
df.to_csv('data/employees_synthetic.csv', index=False)

print(f" Dataset generado: {df.shape[0]} empleados, {df.shape[1]} columnas")

Proposed Solution: A 3-Layer Tech Stack

First Layer: Automated Metrics Dashboard

Business Impact: Reduce manual reporting from 15 hrs/week to 0 hrs/week

Here are the Key metrics that we are going to track: - Turnover Rate (voluntary vs involuntary, by team/department) - Time-to-Hire (from requisition to offer acceptance) - Cost-per-Hire (recruiter time + agency fees + advertising) - Time-to-Productivity (days from hire to full ramp-up) - Engagement Score (from pulse surveys) - Performance Distribution (by manager/team)

import pandas as pd
import numpy as np
import matplotlib.pyplot as plt
import seaborn as sns

df = pd.read_csv('data/employees_synthetic.csv')

total_employees = len(df)
employees_left = len(df[df['status'] == 'Left'])

# Turnover by Type
print(f"\n TURNOVER BY TYPE ")
turnover_by_type = df[df['status'] == 'Left']['termination_type'].value_counts()
turnover_pct_by_type = (turnover_by_type / employees_left * 100).round(2)

    pct = turnover_pct_by_type[tipo]
    print(f"{tipo}: {count} ({pct}%)")

turnover_by_dept = df.groupby('department').agg(
    total=('status', 'count'),

turnover_by_dept = turnover_by_dept.sort_values('turnover_rate', ascending=False)

Second Layer: Predictive Churn Model (Python + Random Forest)

Business Impact: Ability to identify employees with higher risk of leaving, with 90-day period beforehand.

Model Approach: - Target: Binary classification (left within 90 days: Yes/No) - Features: tenure, performance scores, manager changes, compensation ratio, engagement survey responses, time since last promotion - Algorithm: Random Forest (interpretable, handles non-linear relationships) - Output: Risk score per employee + top 3 drivers per person

Key deliverable: Weekly report to managers flagging high-risk employees with recommended interventions.
